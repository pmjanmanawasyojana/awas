Download this phone's entries

Makes one Excel file with the sheets All Entries (with the photos), Summary and Photos. The file is saved in the phone's Downloads folder. Send it to the person collecting the data (WhatsApp, email, Bluetooth or a cable).

Photographs are inside the Excel file twice: in the All Entries sheet next to each entry (Photo 1, Photo 2 … columns after "A10 Photograph taken"), and on the Photos sheet. Download photos also saves the full-size pictures separately, named with the Survey ID.

Restore puts the entries from a downloaded file back onto this phone, for example after changing phones. Survey IDs already saved here are skipped.

Combine files into one master workbook

For the person collecting the data, on a phone or computer. Open this same form file, then add every Excel file the surveyors sent. All entries go into one All Entries sheet, with the Summary and Beneficiary List (who is surveyed) sheets rebuilt, and every photo next to its entry and on the Photos sheet.
